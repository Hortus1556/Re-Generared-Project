# Re Generated Project — docs index

Goal: bring the Amateur Surgeon games to Windows on one engine, **Bleed Engine**: each from its own original (the Flash games from their SWFs, AS2 from its IPA and Flash original, AS3 from its IPA), with the online services removed. Start with [plan.md](plan.md) (where things stand) and [rules.md](rules.md) (how every port is done).
